# 🧠 AI Image Classifier using CNN

AI Image Classifier is a full-stack Deep Learning application designed to classify images into predefined categories (such as **Dog** and **Cat**) using **Convolutional Neural Networks (CNNs)**.

This project demonstrates a complete end-to-end AI workflow, from data preprocessing and model training to backend integration and frontend deployment, making it ideal for learning and practice.

---

## 🚀 Features

### 🖼️ Image Upload & Classification
- Upload images directly through a clean and simple web interface.
- Supports real-time image classification.

### 🤖 CNN-Based Deep Learning Model
- Uses Convolutional Neural Networks to automatically extract visual features.
- Provides accurate and reliable predictions.

### ⚡ Real-Time Predictions
- Backend processes images and returns results instantly.
- Optimized for low latency inference.

### 🧩 Full-Stack Architecture
- Seamless integration of frontend, backend, and AI model.
- Clear separation of concerns for scalability and learning.

## ⚙️ How It Works

1. User uploads an image via the frontend  
2. Image is sent to the backend API  
3. Backend preprocesses the image (resize, normalize, etc.)  
4. CNN model performs prediction  
5. Classified result is returned to the user  

---

## 🧩 CNN Workflow (Simplified)

- **Input Layer:** Accepts the image  
- **Convolution Layers:** Extract features like edges and shapes  
- **Pooling Layers:** Reduce image size while preserving features  
- **Fully Connected Layers:** Learn high-level patterns  
- **Output Layer:** Produces final classification result
